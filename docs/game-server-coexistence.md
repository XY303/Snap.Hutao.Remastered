# 基于转换清单的多服共存（实验性）

从一份已有完整客户端出发，读取国服与国际服的官方 Sophon 转换清单，创建另一服资源视图。界面只提供“按转换清单创建共存”，已移除选择另一份已有安装的入口。

## 目录与启动

例如现有 `D:\Games\Genshin\YuanShen.exe`，将自动生成 `D:\Games\Genshin.hutao-os\GenshinImpact.exe`；从国际服创建国服则使用 `.hutao-cn` 相邻目录。不要求预先安装另一服，也不会覆盖已有目录。

为避免根目录同名 DLL、配置、SDK 和运行时文件冲突，两服入口采用独立目录视图；这不是同时下载两份完整客户端。相同大型资源通过硬链接占用一份磁盘内容，差异资源通过原有转换器的缓存、差异块下载及重建逻辑准备。目标清单中的其他相同文件独立复制，不下载。两服的程序、配置、SDK、Persistent 不共享。

胡桃启动时选择国服则运行 `YuanShen.exe`，选择国际服则运行 `GenshinImpact.exe`；根据账号自动选服也走相同路由。正式名称是 `GenshinImpact.exe` 和 `YuanShen.exe`。不支持两服同时运行。关联期间禁止原地转换或使用 bilibili 等其他渠道。

## 创建与验证

- 仅支持官服默认和国际服默认（channel=1、sub_channel=0）。源客户端的 config.ini 与 ScriptVersion 必须有效且一致，版本必须与两服在线正式清单一致。
- 与区服转换复用同一 Sophon 清单来源、清单校验、差异操作与块下载重建流程。另包括源客户端已安装语音包对应的两服清单，按 MatchingField 排序配对；缺少清单则拒绝创建。
- 仅移除清单路径开头的 `YuanShen_Data/` 或 `GenshinImpact_Data/` 做对应比较，不忽略任意一级目录，避免错误匹配根目录 DLL 或不同目录下同名文件。
- 根目录 `pkg_version` 和 `*_pkg_version` 是启动器维护的可变版本清单，不复用本地内容，也不作为差异块输入。始终按目标服清单完整下载这些小文件，并验证目标长度和 MD5；源文件保留不动。该例外不适用于资源目录里的文件。
- 目标清单每个文件写入前检查源内容长度与 MD5；用于差异重建的旧文件也检查。相同清单项仅在 `_Data/StreamingAssets` 的 `.blk`、`.pck`、`.usm` 且对应源路径一致时建立硬链接，其余文件独立复制。缓存差异文件只复制，不链接。
- 目标路径、缓存路径、块文件名在下载前校验；拒绝路径越界、ADS、目录 Junction 和符号链接。仅限同一台计算机的同一 NTFS 卷。
- SDK 解压使用独立临时文件替换目录项，避免原位写入共享文件；废弃资源备份也使用独立副本。
- 需要网络和额外空间；创建阶段差异缓存与目标独立文件可能同时占用空间。不会抓取完整另一服安装包。

## 确认与兼容性

创建前有两次独立、默认取消的确认。第一次说明限制及兼容性风险，第二次展示源 EXE 和自动生成的目标 EXE，并要求接受仅通过胡桃启动与更新。

**启用期间仅通过胡桃启动、更新、修复和预下载。** 不要直接双击 EXE，不要用官方启动器或第三方工具修改关联目录。程序无法在操作系统层面阻止外部启动或写入。

硬链接不是备份，也没有自动写时复制；写入任一共享文件都可能影响两服。游戏内热更新、官方启动器、反作弊及第三方工具的兼容性未实测，可能出现无法预见的错误，包括资源损坏、校验失败、无法启动和需要重新下载。仅通过胡桃启动不能消除游戏自身修改共享文件的风险。

## 更新、解除与中断恢复

程序内包操作会先恢复当前入口的独立资源，空间估算包含解除共享需要的额外空间，再执行更新、修复或预下载。另一入口保留；更新后不自动重新共享。当前界面不提供旧的“两份安装重新关联”流程；如需重建，先解除，备份或移走已生成目录，再从更新后的源客户端创建。

创建前先在两边写入 `snap_hutao_server_coexistence.json` 恢复记录，包括计划共享项及 `CreationPending=true`。只有资源和 SDK/配置准备完成后，两边才清除此标记。中断或最终化失败会保留记录，胡桃拒绝启动或更新这些入口，避免使用不完整客户端。

失败或取消后先执行“恢复独立并解除关联”，再移走未完成的生成目录并重试。解除操作保留两个目录，不递归删除游戏文件，也不会把未完成目录认定为完整安装；不要启动未完成目录。恢复可能需要大量额外空间，不要手动删除恢复记录或移动仍关联的目录。

已有旧原型恢复记录仍可解除；旧的选择安装关联入口已移除。

## 验证范围

自动化测试使用临时目录、模拟清单内容和真实 NTFS 硬链接，覆盖从单份安装生成两种区服入口、差异资源独立复制、清单哈希错误、路径越界、已有目标保护、创建中断、SDK 最终化失败、禁止未完成入口路由，以及解除后写入隔离。另保留原有硬链接恢复和包操作暂停测试。

尚未在真实游戏、实际在线下载、官方启动器、游戏内热更新或反作弊环境中做端到端验证；未修改本机真实游戏安装。实现可编译和文件系统测试通过，不代表上述兼容性已经成立。
