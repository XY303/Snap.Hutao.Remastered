# ReFS 虚拟磁盘双服共存（实验性）

从一个完整、当前正式版本的官服默认或国际服默认客户端创建双服，不需要提前安装另一服。仅支持官服默认与国际服默认；不支持 bilibili、其他渠道或同时运行两个游戏进程。

## 创建与布局

1. 依次显示两次默认取消的风险确认，包括兼容性未验证、无法预见的错误、管理员权限、首次完整复制、磁盘空间和挂载要求。
2. 确认两服官方当前分支版本与本地版本相同；目标容器必须不存在。新建动态 VHDX，使用普通 ReFS 格式化，并实际探测块克隆。不会安装驱动、开启系统功能、修改安全设置或回退到硬链接。
3. 保留原安装，将一份基础客户端复制到虚拟盘内。跳过根目录 chunks、ScreenShot 及共存管理文件；源文件按普通文件读取，不继承源硬链接关系。
4. 使用区服转换所用的官方 Sophon 与已安装语音清单，准备另一服的差异文件。根目录 pkg_version / *_pkg_version 使用目标清单资源，不复用本地启动器可变清单。
5. 清单确认相同、至少 1 MiB、属于 StreamingAssets 下 .blk/.pck/.usm 白名单的资源，使用同一 ReFS 卷内的 FSCTL_DUPLICATE_EXTENTS_TO_FILE 块克隆。未对齐的尾部和其他文件普通复制。配置、SDK、可执行程序、Persistent 等独立；克隆失败停止，不回退硬链接。
6. 两个客户端及 SDK 完成后清除未完成标记，胡桃选择虚拟盘内的源区服。按服务器或账号类型自动选服切换到对应 EXE。

例如原安装为 `D:\Games\Genshin`：

```text
D:\Games\Genshin\YuanShen.exe                     原安装，保留
D:\Games\Genshin.hutao-vdisk\game.vhdx             动态磁盘文件
D:\Games\Genshin.hutao-vdisk\virtual-disk.json     宿主盘上的卷身份描述
D:\Games\Genshin.hutao-vdisk\volume\CN\YuanShen.exe
D:\Games\Genshin.hutao-vdisk\volume\OS\GenshinImpact.exe
```

`volume` 是固定的卷挂载目录，不是共享游戏目录的目录链接。两服拥有各自的文件对象；ReFS 在写入共享块时分配自己的块。修改、修复和更新一服不会因为硬链接共写而修改另一服。

## 使用、挂载与空间

创建和重新挂载需要以管理员身份运行胡桃，系统需支持 ReFS 格式化、块克隆及 Windows Storage PowerShell 命令。非管理员可使用已经正确挂载的卷。系统不支持时给出错误，可能保留已创建的磁盘文件供检查，不会重新格式化已有磁盘。

启动、刷新游戏信息和包操作前自动尝试挂载所选安装。也可从原安装使用“挂载并选择虚拟盘”。挂载只连接既有镜像并核对保存的卷 GUID；目录被其他卷占用、描述文件丢失、镜像缺失或挂载失败时停止。Windows 卸载后保留的挂载点 GUID 不代表设备在线，必须验证实际可访问的 ReFS 卷。禁止把离线挂载目录当普通宿主目录写入。

动态磁盘最大容量按基础文件体积的三倍加 32 GiB 向上取整，最少 64 GiB；初始宿主剩余空间要求基础副本加 16 GiB。最大容量不代表已经分配的物理空间，也不保证以后有足够空间。创建另一服和包操作同时考虑卷内与宿主可用空间；差异重建缓存位于胡桃现有数据缓存目录，也可能占用另一个宿主卷。

首次复制实际占用一份客户端空间，需要时间；双服更新分歧、热更新和缓存会持续增加实际占用。不会自动扩容、收缩或重新去重。不要在游戏、更新或胡桃资源操作期间卸载、移动或删除 VHDX、挂载目录或描述文件。胡桃退出时不主动卸载，避免影响仍运行的游戏；重启系统后可能需要重新挂载。

## 普通修复、解除与失败恢复

已删除“强行修复”按钮及专用删链接修复逻辑。ReFS 文件独立，不需要在每次更新、校验修复或预下载前复制/删除共享资源。普通“修复游戏”继续完整校验并修复选中区服；成功校验可解除该客户端的创建未完成标记。

创建前先在两个客户端目录写入版本 2 恢复记录，含镜像路径与未完成标记。未完成客户端不允许启动或更新。取消或失败保留原安装、虚拟盘和已完成的文件；不覆盖目标容器，不自动删除大文件。磁盘格式化期间的取消会在 Windows 存储操作到达稳定边界后生效。

若虚拟盘内客户端的程序及配置已经就绪，可挂载后分别选择两服进行普通修复。若基础复制或建盘阶段就中断，客户端可能尚不具备可修复的入口；此时继续使用原安装，关闭相关程序、卸载该测试盘后备份或移走整个旧容器，再重新创建。当前不支持续建、不自动导出到宿主普通目录。

“解除选服关联”只删除两服路由记录，保留两个独立文件树及虚拟盘描述，之后仍需挂载才能使用；ReFS 已隔离写入，无需把克隆资源再复制一遍。旧版本 1 硬链接记录仅保留安全解除能力，解除时仍需复制独立文件；不再从界面创建新的硬链接共存。

## 兼容性与验证范围

仍为实验性功能，两次确认明确提示兼容性问题和可能无法预见的错误。请仅通过胡桃启动、更新与修复。写时复制不是备份，不保证原神、游戏内热更新、官方启动器、反作弊或第三方工具接受该文件系统和挂载路径。

自动测试使用模拟客户端，包含两个方向的真实临时 VHDX 创建、ReFS 格式化、清单生成、物理块克隆确认、未对齐尾部、独立写入、卸载重新挂载、解除关联和 NTFS 拒绝回退。完整测试 283 项通过（需要管理员和 HUTAO_VHD_INTEGRATION=1；默认跳过两项虚拟盘集成测试）。没有将真实游戏迁移到新后端，未完成真实游戏启动、更新、反作弊及断电恢复验证。

此前真实国服客户端已解除旧共存并完成普通完整性修复；这不代表新后端的游戏兼容性已验证。其他方案评估见 [原神共存存储方案评估](game-storage-backends-evaluation.md)。
